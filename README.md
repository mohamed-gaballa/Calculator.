# 🧮 My Calculator

A simple calculator project designed to perform everyday mathematical calculations with ease.

## 📌 About the Project
This project provides a simple interface for entering numbers and performing basic arithmetic operations.

## ⚙️ Operations
- Addition (+)
- Subtraction (-)
- Multiplication (×)
- Division (÷)

## 💻 Built With
- HTML
- CSS
- JavaScript

## 🎯 Project Goal
To practice front-end development skills and build an interactive web application.
